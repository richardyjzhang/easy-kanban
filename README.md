# 🗂️ easy-kanban

> 面向小型研发团队管理者的「人 × 项目」矩阵看板，把每个人在做什么、每个项目都有谁在跟，放在一张表里看清楚。

---

## 😵 它想解决的问题

几个人、几个项目同时推进，任务分配本质上是一个 **M×N 矩阵**：一个人参与多个项目，一个项目多人参与。

但这张矩阵通常不存在于任何地方——它散在群聊、口头交代和你的记忆里。于是每次被问起，你都要现场回忆、翻记录，还经常答不全。

现成的看板工具都在回答「有哪些事要干」，没有人在回答「**谁在给哪个项目干活**」。

## ✨ 核心想法

### 🔁 一键转置：矩阵才是主视图

行是人、列是项目；一个按钮换过来，行是项目、列是人。

同一个信息，换一个方向看，就是另一类问题的答案：

- 竖着看：A 项目谁在干？谁空着？
- 横着看：张三这周都在忙什么？被几个项目分了身？

大多数看板工具靠筛选器模拟这件事，你得点五次才勉强拼出全貌。这里就是一次点击。

### 🕳️ 空格子也是信息

矩阵真正的价值不在填满的格子，而在空着的那些：

- **整行为空** → 这个人最近没活
- **整列为空** → 这个项目没人跟进

它们被特意高亮出来，而不是藏起来。

### 🗓️ 临时的事不会被筛没

任务有开始日和截止日，但都可以留空。写不出日期的临时任务不参与时间筛选，**在任何周视图下都显示**——否则一切到「本周」，它们就人间蒸发了，等于忘了。


## 📱 两端不同形态

- **PC**：精致、留白、支持拖拽
- **H5**：紧凑、横向滚动、首列吸附，随手查一眼

同一套数据，两种布局，不是简单缩放。

## 🚀 开始使用

```bash
git clone <repo>
cd easy-kanban
```

部署步骤见 [docs/DEPLOY.md](docs/DEPLOY.md)：Nginx 子路径、systemd 托管、首次部署手动执行 `schema.sql` 初始化数据库。
