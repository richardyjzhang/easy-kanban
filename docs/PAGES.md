# easy-kanban 页面与模块设计

> 版本：v0.1（草稿）· 日期：2026-11-23 · 配套 [PRD.md](PRD.md)

---

## 1. 设计前提

| 项 | 约定 |
|---|---|
| 用户 | 单账号、单用户，无协作概念 |
| 终端 | PC 与 H5 **两套独立布局、各自路由**，不共用页面骨架 |
| 共用部分 | 数据层（stores + API client）、基础原子组件、类型定义 |
| UI 组件库 | Naive UI（深蓝主题），图标使用 `@vicons/ionicons5` |
| 部署 | 子路径 `/easy-kanban/`，前端使用 hash 路由，地址形如 `/easy-kanban/#/pc` |
| 观感 | PC 精致、留白充足；H5 紧凑、信息优先、单手可达 |

不做的界面：我的任务、通知中心、评论、协作成员管理、导入导出页、数据看板。

## 2. 信息架构与路由

| 路由 | 端 | 页面 | 说明 |
|---|---|---|---|
| `/` | 共用 | 入口分流 | 按 UA 跳 `/pc` 或 `/m`；未登录跳 `/login` |
| `/login` | 共用 | P1 登录 | 未登录时唯一可达页面 |
| `/pc` | PC | P2 矩阵 | 默认页 |
| `/pc/settings` | PC | P3 设置 | 人员／项目／账号 |
| `/m` | H5 | P4 矩阵 | 默认页 |
| `/m/settings` | H5 | P5 设置 | 列表式入口 |

待分配不是一个页面，而是矩阵里固定存在的第一行（系统人员），两端共用同一套逻辑。

路由守卫：除 `/login` 外全部要求登录；已登录访问 `/login` 自动跳回默认页。

## 3. 共用层模块

```
src/
├─ api/            # client.ts（baseURL = BASE + '/api'，注入 Bearer，统一错误）
├─ stores/         # auth / people / projects / tasks / filters / ui
├─ components/     # 通用组件与业务组件（TaskForm、TaskListPanel、设置页分区等）
├─ layouts/        # 页面外壳（当前为 PC 的 AppLayout；M4 增加 H5 外壳）
├─ pages/          # 路由页面（LoginPage、MatrixPage、SettingsPage）
├─ types/          # Person Project Task 及请求/响应类型
├─ utils/          # 日期格式化、滚动锁等纯函数
└─ styles/         # 全局样式与设计变量
```

**数据加载策略**：进入矩阵时一次性拉取全量人员、项目与任务（规模上限 2000 条），前端按 `(person_id, project_id)` 建索引分组；切换周、转置、拖动均不触发网络请求。所有写操作走乐观更新，失败回滚。

## 4. 页面清单

### P1 登录页

- **目的**：拦住公网访问，不做账号体系。
- **模块**：居中卡片、用户名输入、密码输入、登录按钮、错误提示。
- **交互**：回车提交；错误时输入框抖动 + 文案。
- **不包含**：注册、忘记密码、第三方登录。

### P2 PC 矩阵页（核心）

- **顶部栏**：产品名 · 日期筛选（本周／下周／全部／自定义）· 转置按钮 · 设置入口 · 退出登录。
- **矩阵区**：左侧人员列 180px 固定，表头 140px 固定，格子最小宽度 160px，双向滚动；列宽固定，不支持手动调整。
- **格子**：状态点 + 标题 + 日期（无日期显示「—」），最多 3 条，超出「+N」；hover 显示「+」快速新建；点状态点循环切换；空白处点击开格子弹窗。
- **行头／列头**：颜色点 + 名称；可拖动排序；拖动时整行／整列浮起，落点处撑开插入间隙，松手后生效。
- **待分配行**：第一行固定为系统人员，灰底 + 锁标识，行头显示未指派数量；为空时压缩成窄行，但始终可作拖放目标。
- **空行／空列**：虚线边框 + 淡黄底，行头显示「无任务」标记。
- **空状态**：无人员或无项目时，矩阵区替换为引导卡片，按钮直达设置页。人员与项目都在、仅当前筛选无任务时，矩阵照常渲染，网格上方显示一条提示条（「新建任务」或「查看全部」）。
- **加载中**：骨架屏（灰色格子矩阵）。**出错**：顶部错误条 + 重试。

### P3 PC 设置页

顶部分区 Tab（人员／项目／账号）+ 下方内容卡片，三个分区：

| 分区 | 内容 |
|---|---|
| 人员 | 表格：颜色、姓名、进行中任务数、操作（编辑／归档）；顶部「新建人员」；列表底部「已归档 (N)」折叠组，展开显示归档人员及其任务数，可恢复 |
| 项目 | 表格：颜色、名称、描述、进行中任务数、操作；顶部「新建项目」；同样带「已归档 (N)」折叠组 |
| 账号 | 修改密码（旧密码 + 新密码 + 确认）、退出登录 |

不设独立的归档页，归档条目就近归入人员／项目各自的列表底部；人员列表不含内置的「待分配」。

### P4 H5 矩阵页

- **顶部栏**（单行，高度 ≤ 52px）：筛选下拉（显示当前范围）· 转置图标按钮。
- **矩阵区**：横向滚动，首列人员列 96px 吸附，格子宽 120px，每格仅 1 条任务标题，超出「+N」；第一行为「待分配」，样式与 PC 一致。
- **底部 Tab**：矩阵 / 设置，两个入口。
- **点格子**：从底部弹出全屏 sheet，展示该格任务列表与新建按钮；「待分配」行的 sheet 里点任务即可选人员指派。
- **不做拖拽**：任务改归属在任务弹窗里用「人员／项目」下拉完成；人员与项目的顺序在设置页用「上移／下移」按钮调整。

### P5 H5 设置页

单列列表，每项进入独立全屏子页：

- 人员管理（列表 + 新建／编辑／归档；底部「已归档」折叠组可恢复）
- 项目管理（同上）
- 修改密码
- 退出登录

## 5. 弹窗与弹层

| 编号 | 名称 | 载体 | 说明 |
|---|---|---|---|
| D1 | 格子弹窗 | PC 居中 Modal（宽度随内容在 880–1200px 间自适应）/ H5 全屏 sheet | 标题「张三 · 支付重构」，任务表格按时间排序，底部「新建任务」 |
| D2 | 任务弹窗 | PC 居中 Modal（560px）/ H5 全屏 sheet | 编辑全部字段、切换状态、删除；保存即时生效 |
| D3 | 快速新建 | 轻量弹层 | 仅标题输入，人员／项目／日期已带入，回车保存；「更多字段」展开完整表单 |
| D4 | 确认弹层 | 模态 | 删除（项目需输入名称）、归档、放弃未保存修改 |
| D5 | Toast | 顶部浮层 | 成功提示 + 撤销入口（5 秒） |
| D6 | 日期范围 | PC 弹出层 / H5 底部弹层 | 预设三项 + 自定义起止日 |

## 6. 组件清单

> 按钮、输入框、表格、弹层、提示等通用交互由 Naive UI 提供；下面只列业务组件。

| 组件 | 职责 |
|---|---|
| `MatrixGrid` | 网格布局、滚动同步、行列表头吸附、行列拖拽排序、任务拖拽改归属与落点高亮（行头／列头内联在此） |
| `MatrixCell` | 单格任务堆叠、`+N`、hover 新建、状态点切换与「待分配」窄格 |
| `TaskChip` | 状态点 + 标题 + 日期（无日期显示「—」），点状态点循环切换 |
| `FilterBar` | 预设范围（本周／下周／全部／自定义）与当前区间显示 |
| `CellModal` | 格子弹窗 D1：该格全部任务、状态切换、编辑／删除与新建入口 |
| `QuickCreateModal` | 快速新建 D3：只收标题，回车保存；「更多字段」切到 `TaskModal` |
| `StatusDot` | 状态色点，配合 Naive UI `NTag` 使用 |
| `TaskForm` | 新建／编辑共用表单与校验 |
| `TaskListPanel` | 任务列表容器，分组与排序（`showContext` 控制人员／项目列） |
| `TaskModal` | 任务弹窗 D2：编辑全部字段、删除 |
| `PeopleSection` / `ProjectsSection` | 设置页人员／项目表格、归档分组与恢复 |
| `PersonDialog` / `ProjectDialog` | 新建／编辑人员与项目 |
| `ColorDot` / `ColorPicker` | 颜色展示与色板选择 |
| `AccountSection` | 修改密码与退出登录 |

转置按钮与空状态文案当前直接写在 `MatrixPage` 里，未单独拆组件。

## 7. 交互与反馈约定

- **乐观更新**：拖拽、状态点击、归档先改本地状态，请求失败回滚并 toast 报错。
- **拖拽反馈**：拖起时目标格子高亮，非法落点（无）不特殊处理，全部格子都可落。
- **待分配**：任务是「待分配」这一行的内容，拖出该行即指派，拖回该行即取消指派；H5 通过任务弹窗下拉完成。
- **防误触**：删除、归档均二次确认；删除项目需输入名称。
